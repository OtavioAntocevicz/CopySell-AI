# Deploy

## Build

```bash
npm run build
npm run start
```

## Runtime

- Node compativel com Next 16.
- Variaveis obrigatorias: ver [variaveis-ambiente.md](./variaveis-ambiente.md).

## Supabase

- Aplicar migrations no projeto remoto (Dashboard SQL ou CLI).
- Configurar Auth redirect URLs para dominio de producao (`/auth/callback`).
